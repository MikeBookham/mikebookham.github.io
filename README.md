## About
This repository contains the files for my personal site.

## Built With
*   **HTML/CSS** - Structure and styling
*   **GitHub Pages** - Hosting platform

## Getting Started
To view the site locally:

1.  Clone this repository:
    ```bash
    git clone [https://github.com/MikeBookham/mikebookham.github.io.git](https://github.com/MikeBookham/mikebookham.github.io.git)
    ```

2.  Open the index file in your web browser:
    ```bash
    cd mikebookham.github.io
    open index.html
    ```
